# Dev log: stage 1, four-neuron ring (2026-11-16)

Branch: `pattern-generator`. `main` still holds the verified single-neuron design (149 cells, 8.3% utilization).

## Goal

Grow the single LIF neuron into a spiking pattern generator that uses more of the 1x1 tile, and can be shown on the demo board as a travelling spike pattern.

## Design

```
ui_in ──► N0 ──► N1 ──► N2 ──► N3
          ▲                    │
          └────────────────────┘
```

- The neuron logic moved into its own module, `lif_neuron`. Its input current is now signed and V floors at 0, ready for inhibition in a later stage.
- Four neurons are wired in a ring. Only neuron 0 gets the external input `ui_in`.
- A spike adds a "kick" of weight W to the next neuron, one clock later (spikes are registered).
- `uio_in[1:0]` selects W: 0 (ring off), 64, 128 or 255.
- `uo_out` is unchanged: `{V0[7:1], spike0}`. `uio_out[7:5]` carries the spikes of neurons 3, 2, 1.
- With the weight select at 0, neuron 0 behaves exactly like the original design, so the six original tests run unchanged as a regression check.

## Prototype first

Before any RTL changed, the ring was prototyped in Python from the existing golden model. Input 30:

```
weight 255
n0 ........|............|............|....
n1 .........|............|............|...
n2 ..........|............|............|..

n1 ...................................|...
```

## Verification

New files: `test/ring_model.py` (golden model of the ring) and `test/test_ring.py` (five tests that compare all four spikes with the model every cycle).

RTL simulation, Icarus Verilog 13.0 with cocotb 2.1.0: `TESTS=11 PASS=11 FAIL=0`.

| Test | Result |
|---|---|
| Six original single-neuron tests | Pass, unchanged |
| `test_travelling_wave` (weight 255, input 30) | 9 spikes per neuron; neurons 1, 2, 3 follow neuron 0 one clock apart |
| `test_rate_division` (weight 128, input 30, 400 cycles) | Spikes per neuron 31, 10, 0, 0 |
| `test_ring_off` | Only neuron 0 fires |
| `test_quiet_without_input` | No spikes at any weight |
| `test_random_ring_vs_model` (5,000 cycles, random weights and resets) | Spikes per neuron 426, 123, 86, 81; every cycle matched |

## Goal of stage 2

Make the chip test itself, so one pin setting on the demo board says whether the neurons work. This is design for test (DFT): the stimulus generator and the checker are on the chip.

## Design

```
            ┌──────────┐  stimulus   ┌──────────────┐  spikes, V0[7:4]  ┌──────────┐
BIST pin ──►│ counter  ├────────────►│ 4-neuron ring├──────────────────►│   MISR   ├──► == 0x55C4 ? ──► PASS
            │ + LFSR   │ weight/mode └──────────────┘                   │ 16 bits  │
            └──────────┘                                                └──────────┘
```

- **LFSR:** 8 bits, x^8 + x^6 + x^5 + x^4 + 1, period 255. Pseudo-random input current for neuron 0.
- **Counter:** 11 bits. The first clock resets the neurons, then 1024 clocks of stimulus. Its bits step through all four weights (every 256 clocks), both refractory modes (every 128) and small or large currents (every 64).
- **MISR:** 16 bits, x^16 + x^12 + x^5 + 1. Folds in the four spikes and V0[7:4] every clock.
- **Result:** DONE after 1025 clocks. PASS if the signature equals `0x55C4`.
- **Pins:** `uio[3]` starts the self-test. `uio[4:3]` selects what `uo` shows: neuron 0 (00), self-test status (01), signature high byte (11), reserved (10).

Page 00 is the old behaviour, so every earlier test runs unchanged.

## Model first

`test/chip_model.py` is a pin-accurate model of the whole chip. The golden signature comes from running the self-test on that model:

```
LFSR period 255, spikes per neuron during BIST [115, 50, 40, 37], golden signature 0x55c4
  faulty threshold 199: signature 0xc036
  faulty threshold 201: signature 0x2ff6
```

All four neurons fire during the self-test, and a threshold that is off by one changes the signature.

## Verification

RTL simulation: 20 tests on the normal build, plus 1 on a deliberately faulty build.

| Test | What it shows |
|---|---|
| `test_bist_passes` | DONE after exactly 1025 clocks, PASS set, signature 0x55C4 |
| `test_bist_ignores_other_pins` | Random `ui_in`, weight, mode, `ena` and unused pins do not disturb the self-test |
| `test_bist_restarts_cleanly` | Leaving early, or a reset mid-run, does not spoil the next run |
| `test_reserved_page_reads_zero` | Page 10 reads 0 and the ring keeps running |
| `test_random_chip_vs_model` | 8,000 random clocks with page changes; every output pin matches the model |
| `test_golden_constant_matches_model` | The constant equals what the model produces |
| `test_bist_catches_wrong_threshold` | Built with THRESHOLD = 201: DONE without PASS, signature 0x2FF6 |
| `test_input_adds_to_ring_kick` | Directed test of the ring-closing adder, a gap the verifier found |

The last row of the fault test matters most: a self-test that can only say PASS proves nothing.
